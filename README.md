# CodeEval AI 🚀
### AI Coding Reliability Benchmark Platform

**CodeEval AI** is a benchmark platform designed to evaluate the reliability, correctness, and performance of AI-generated code using automated test cases and deterministic scoring.

The platform helps compare coding solutions generated by different AI models, identify common programming mistakes, and analyze where AI-generated code fails.

---

## 🎯 Project Objective

The main objective of CodeEval AI is to measure how reliable AI-generated programming solutions are.

Instead of judging code only by how it looks, CodeEval AI evaluates solutions by executing them against predefined test cases.

It focuses on:

- Code correctness
- Automated test execution
- Deterministic scoring
- AI model comparison
- Failure analysis
- Programming problem difficulty levels

---

## ✨ Key Features

- **Automated Code Evaluation:** Execute submitted Python solutions against predefined test cases.
- **Deterministic Scoring:** Calculate scores based on evaluation results.
- **Multiple Programming Problems:** Includes Easy, Medium, and Hard-level tasks.
- **AI Model Comparison:** Compare results from different AI models.
- **Failure Analysis:** Identify failed test cases and understand coding errors.
- **Interactive Dashboard:** View evaluation summaries and benchmark results.
- **REST API:** Integrate code evaluation through FastAPI endpoints.
- **Reference Solutions:** Use predefined solutions to validate benchmark tasks.

## 📚 Benchmark Dataset

The current benchmark dataset contains 10 programming problems across three difficulty levels.

### Easy Problems

| ID | Problem | Function |
|---|---|---|
| CE-E01 | Second Largest Distinct Value | `second_largest(nums)` |
| CE-E02 | Alphanumeric Palindrome | `is_palindrome(s)` |
| CE-E03 | Merge Two Sorted Lists | `merge_sorted(a, b)` |

### Medium Problems

| ID | Problem | Function |
|---|---|---|
| CE-M01 | Maximum Subarray Sum | `max_subarray_sum(nums)` |
| CE-M02 | First Occurrence Binary Search | `binary_search_first(nums, target)` |
| CE-M03 | Group Anagrams | `group_anagrams(words)` |
| CE-M04 | Balanced Brackets | `valid_parentheses(s)` |

### Hard Problems

| ID | Problem | Function |
|---|---|---|
| CE-H01 | Longest Increasing Subsequence | `longest_increasing_subsequence(nums)` |
| CE-H02 | Edit Distance | `edit_distance(a, b)` |
| CE-H03 | Count N-Queens Solutions | `n_queens_count(n)` |

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/riteshparashar-ctrl/CodeEval-AI.git
```

### 2. Open the Project Folder

```bash
cd CodeEval-AI
```

### 3. Create a Virtual Environment

```bash
python -m venv .venv
```

Activate it:

**Windows:**
```bash
.venv\Scripts\activate
```

**Linux / macOS:**
```bash
source .venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Validate the Benchmark Dataset

```bash
python run.py validate
```

### 6. Run Automated Tests

```bash
python run.py test
```

### 7. Start the Application

```bash
python run.py serve
```
*(Or simply `python run.py`, `python app.py`, or `python main.py`)*

Open the application in your browser:

- **Dashboard:** [http://127.0.0.1:8000](http://127.0.0.1:8000) (or `/index.html`)
- **Submit Code:** [http://127.0.0.1:8000/submit](http://127.0.0.1:8000/submit) (or `/submit.html`)
- **Failure Analysis:** [http://127.0.0.1:8000/failures](http://127.0.0.1:8000/failures) (or `/failures.html`)
- **API Documentation (Swagger UI):** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## 🧪 How to Use CodeEval AI

1. Open the CodeEval AI dashboard.
2. Navigate to the code submission page.
3. Select a benchmark programming problem.
4. Enter the AI model name and version.
5. Add the run number.
6. Paste the Python solution generated by the AI model.
7. Submit the code for evaluation.
8. Review the score, test results, and failure analysis.

The evaluator executes the submitted solution against predefined test cases and generates an evaluation result.

## 📊 Evaluation Methodology

CodeEval AI follows a structured evaluation process:

1. **Problem Selection:** Select a programming task from the benchmark dataset.
2. **Code Submission:** Submit an AI-generated Python solution.
3. **Code Execution:** Execute the submitted solution using the evaluator.
4. **Test Case Validation:** Compare actual outputs against expected outputs.
5. **Score Calculation:** Generate a deterministic score from the evaluation results.
6. **Failure Analysis:** Identify failed test cases and analyze incorrect outputs.
7. **Model Comparison:** Compare evaluation results across different AI models.

## 🔍 Why CodeEval AI?

AI-generated code can look correct but still fail when executed.

A solution may pass basic examples but fail on edge cases, duplicate values, empty inputs, or larger datasets.

CodeEval AI aims to make AI coding reliability measurable through automated and repeatable testing.
